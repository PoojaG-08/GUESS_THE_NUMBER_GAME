# 🎯 Guess The Number Game

A fun and interactive **Guess The Number** game built using **HTML, CSS, and JavaScript**.  
The player has to guess a randomly generated number between **1 and 100** with instant feedback for each attempt.

---

## 🚀 Features

- 🎮 Random number generation
- 📈 "Too High" and 📉 "Too Low" hints
- 🎉 Winning message on correct guess
- 🔄 Restart game functionality
- 🏆 Best score tracking using Local Storage
- ✨ Modern arcade-inspired UI design
- 📱 Responsive design for all devices

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**

---

## 🎯 Game Rules

- Enter a number between **1 and 100**
- The game will tell you if your guess is:
  - Too High 📈
  - Too Low 📉
- Keep guessing until you find the correct number
- Try to beat your best score 🏆
